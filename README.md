# 🔥 Arab Camp Discord Management Portal

منصة ويب متكاملة وبوت ديسكورد مصمم خصيصاً لإدارة عمليات التقديم والانضمام لطاقم الإشراف والإدارة في سيرفر **Arab Camp**.

## 🚀 المميزات الرئيسية
* **تسجيل الدخول عبر Discord OAuth2:** مصادقة أمنية وسريعة للتحقق من هوية الأعضاء.
* **لوحة تحكم تفاعلية (Dashboard):** نموذج تقديم متكامل يحتوي على أسئلة محددة لقياس كفاءة المتقدمين.
* **نظام إرسال تلقائي للرومات:** إرسال التقديمات تلقائياً إلى روم الإدارة المخصص مع تضمين (Embed) منسق.
* **أزرار تفاعلية للقبول والرفض:** تتيح للإدارة اتخاذ القرار (قبول ✅ / رفض ❌) بضغطة زر واحدة.
* **إشعارات خاصة (DM):** إرسال رسالة خاصة تلقائية للمتقدم بنتيجة طلبه فور اتخاذ القرار.

## 🛠️ التقنيات المستخدمة
* **Node.js**
* **Express.js**
* **Discord.js (v14)**
* **EJS (Embedded JavaScript Templates)**
* **Axios & Express-Session**
